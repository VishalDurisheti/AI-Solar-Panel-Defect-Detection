# ☀️ AI-Based Solar Panel Defect Detection System

An AI-powered solar panel monitoring dashboard built using Deep Learning, TensorFlow, VGG16, and Streamlit.

## Features

- Solar panel defect detection
- AI-based image classification
- Interactive monitoring dashboard
- Dynamic panel visualization
- Streamlit interface

## Defect Classes

- Bird-drop
- Clean
- Dusty
- Electrical-damage
- Physical-Damage
- Snow-Covered

## Technologies Used

- Python
- TensorFlow
- Keras
- Streamlit
- NumPy
- PIL
- VGG16

## Run Project

```bash
streamlit run app.py
